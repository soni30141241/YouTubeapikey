RAILWAY SETUP

1. Push these files to the GitHub repository root.
2. Railway deploys the Procfile automatically.
3. Add these Railway Variables:
   API_ID = your Telegram API ID
   API_HASH = your Telegram API hash
   BOT_TOKEN = a NEW bot token from @BotFather
   RONAK_API_URL = https://web-production-308f7.up.railway.app
4. Redeploy.
5. Open /docs and confirm it says Royal Fast API 1.0.0.

IMPORTANT: Never commit API_HASH or BOT_TOKEN to GitHub.
The old token from the original ZIP should be revoked and replaced.
